# WitnessFitness technical deck

This deck follows `presentation/technical-presentation-script.md`. It is separate from the older pitch deck in `presentation/deck/`.

## Run

```bash
cd presentation
python3 -m http.server 8766
```

Open `http://127.0.0.1:8766/technical-deck/`.

## Controls

- `→` / `Space`: next slide
- `←`: previous slide
- `S`: speaker view with the full script in notes
- `O` / `Esc`: overview
- `F`: fullscreen
- `B` / `.`: blackout before switching to the live demo

The ten slides target a six-minute delivery. Cue times appear in the lower-right corner.
